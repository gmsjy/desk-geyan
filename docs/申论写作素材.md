## 怎么用：三个位置

申论大作文里引语的落点其实只有三个，能省一半篇幅的纠结。

**① 开头点题（1 句）**
先引一句，再把它「翻译」成你的观点，不要引完就断。

> 「民为邦本，本固邦宁。」**民生从来不是发展的负担，而是发展的目的本身。**

**② 分论点论证（每个分论点 1 句）**
引语后面必须接你的分析，否则是「掉书袋」。

> 正如《管子》所言，「政之所兴在顺民心」——**一项政策能不能落地，最终取决于它有没有回应真实的生活。**

**③ 结尾升华（1 句）**
用气韵强、有画面感的。避免再用开头那句。

> 「望得见山、看得见水、记得住乡愁。」**……**

## 三条纪律

1. **不加「有人说」**。出处写清楚，是申论拿分的细节。这批素材每条都能追到具体出典。
2. **不对句堆砌**。一段里连引两句以上，看起来像摘抄而非思考。一段一句足够。
3. **引完要「翻译」**。用白话把古文的意思接上你的论点，这一步才是得分点。

## 挂件侧怎么用

这批素材已经写进挂件的格言库（`quotes.txt`），跑马灯会滚动它们。几个配合建议：

| 目的 | 配置 |
| --- | --- |
| 每天被动过一遍 | `anim=marquee`，`speed=45`（慢一点好读） |
| 只看某一天不换句 | `anim=static`，`speed` 无关 |
| 逐字看清晰版 | `scale=130`，`mode=glass`，`opacity=230` |
| 考前突击某一类 | 把 `quotes.txt` 里**其他分区整段删掉**（保留要背的两三类），`Ctrl+Alt+R` 重载 |
| 临时跳到下一句 | `Ctrl+Alt+→` |

配置在 `%APPDATA%\DeskGeyan\config.ini`，或直接按热键切（见 README「快捷键」一节）。
